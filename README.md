# Odin Sign-Up Form

This is a  sign-up form project from the Odin Project's Intermediate HTML and CSS course.

The goal of this project is sto practice building a two-column web page layout using HTML forms, CSS positioning, custom fonts, background images, and form validation styles.

## Features

- Two-column layout with a hero image section and a sign-up form section
- Custom Odin logo area using the Norse font
- Background image with photo credit
- Styled form inputs with focus and invalid states
- Submit button styled with the recommended Odin color
- Basic HTML form validation using 'required', 'type', and 'minlength'

## Built With

- HTML
- CSS
- Custom font using '@font-face'

## What I Learned

Through this project, I practiced:

- Structuring a page with semantic HTML
- Creating a full-page flexbox layout
- Using CSS Grid for form fields
- Styling form controls and validation states
- Positioning elements with 'position: relative' and 'position: absolute'
- Using custom fonts and background images
